# Customer Segmentation Analytics

## Descripción

**Customer Segmentation Analytics** es un proyecto desarrollado en Python con elobjetivo de simular una base de clientes y realizar análisis de datos para identificar patrones de comportamiento, segmentar clientes y generar información útil para la toma de decisiones de negocio.

El proyecto está diseñado siguiendo una arquitectura modular y buenas prácticas de desarrollo, permitiendo escalar fácilmente la generación de datos, el análisis exploratorio y la construcción de dashboards.

## Objetivos

* Generar un dataset sintético con información demográfica, financiera y de comportamiento.
* Aplicar técnicas de análisis exploratorio de datos (EDA).
* Identificar los clientes con mayor valor para el negocio.
* Construir visualizaciones y dashboards interactivos.
* Desarrollar un proyecto de portafolio con enfoque profesional en Data Analytics.
